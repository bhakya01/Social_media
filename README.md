# Social Media Data Analysis

## 📌 Project Overview

This project performs a complete **Social Media Data Analysis** workflow using Python. The dataset is imported, cleaned, explored, transformed, statistically analyzed, and visualized to identify meaningful patterns in social media engagement.
The analysis focuses on metrics such as **likes, comments, shares, impressions, watch time, engagement rate, followers, sentiment, post type, category, country, gender, age, verification status, and device type**.
The project uses **Pandas, NumPy, Matplotlib, Seaborn, and Plotly** to perform data analysis and create visualizations.\
## 🎯 Objectives
The main objectives of this project are:
* Import and inspect the social media dataset.
* Clean missing and duplicate data.
* Correct incorrect data types and unrealistic values.
* Standardize categorical variables.
* Extract useful features such as hashtag count.
* Explore relationships between social media metrics.
* Perform statistical analysis.
* Create meaningful visualizations.
* Compare engagement across post types, categories, countries, devices, and sentiments.
* Identify important business and behavioral insights.
